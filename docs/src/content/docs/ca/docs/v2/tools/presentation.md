title: Presentació
---

The Presentation tool animates the camera across a page. You can move and zoom the view between keyframes, pause at breakpoints, and play the result as a presentation. Add the tool from **Add**, then select it to open the presentation toolbar.

## Create an animation

1. Open the animation menu in the presentation toolbar and choose **Create**. Give the animation a name.
2. Move to a frame on the timeline. Position and zoom the canvas where you want the camera to be at that point.
3. Open the **Keyframe** menu. Add a camera keyframe to record the current position and zoom. Add more keyframes at later frames to create movement between them.
4. Use **Play** to preview the animation and **Stop** to return to its start. The timeline and frame field let you jump to a specific frame.

The Keyframe menu can also record only **Position** or **Zoom**. A **Breakpoint** pauses playback at that frame. Remove an unwanted key from the same menu after selecting its frame.

## Adjust and present

Use the animation menu to duplicate, rename, or delete an animation. The settings menu controls **FPS** (frames per second), the current frame, and the animation's duration. A longer duration gives you more frames to work with; FPS controls playback speed.

Open the presentation menu and choose **Play** to enter presentation mode. Butterfly shows the available controls before starting and offers a full-screen option. The same menu can export the animation to PDF using its camera positions and breakpoints. For other output formats, see [Exporting](../../exporting/).

## Animation settings

Animation settings are available after you select the tool:

| Setting   | Default    | Descripció                                                                          |
| --------- | ---------- | ----------------------------------------------------------------------------------- |
| FPS       | 24         | Frames played each second.                                          |
| Durada    | 250 frames | Total length of the animation timeline.                             |
| Keyframes | Cap        | Camera position, zoom, and breakpoints recorded at selected frames. |
