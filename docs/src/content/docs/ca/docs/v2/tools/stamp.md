---
title: Stamp tool
---

The stamp tool allows you to add components to your canvas.
Use an existing pack, create your own or import a pack to use it. Read more [here](../../pack).

## Configuration

| Property  | Default | Descripció                                                                                                                                      |
| --------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Component | Cap     | The selected component from a pack to place on the canvas. You can clear the selection in the properties panel. |
