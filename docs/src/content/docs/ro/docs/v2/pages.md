---
title: Pagini
---

Pages are a way to organize your notes by allowing separate infinite canvases to be contained in a single document.

:::note

Pages are **not** used to create regions on the infinite canvas. To create canvas regions, use [Areas](../areas).

:::

## Open and create pages

Open **Pages** from the Butterfly menu or the navigator. Select a page in the list to open it. The create bar offers four positions for a new page: before or after the current page, first, or last.

Each page has its own canvas. Switch between pages to keep separate parts of a note together in one Butterfly document. To mark a location _within_ a page, use a [waypoint](../waypoints/) instead.

## Organize pages

Drag a page in the list to change its order. Open a page's menu to duplicate it, select it, or delete it. You can also edit its name directly in the list. The current page cannot be deleted from its own menu.

To create folders of pages, add a `/` in the name of a page, such as `Chapter 1/Notes`. The Pages navigator shows **Chapter 1** as a folder. Open that folder to reach **Notes**, and use the location field or up button to move between folders. Renaming a page with another slash path moves it within the page list.

For bulk operations, select a page from its menu or long press it to enter selection mode. You can then select more pages and delete the selection. The page number toggle shows internal page numbers and enables the range field for selecting pages by number.

If you need fixed regions for [PDF export](../exporting/#export-a-pdf) or want to restrict edits to part of a canvas, use [areas](../areas/) within a page.
