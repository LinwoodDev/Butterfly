## Ваша работа принадлежит вам

<CardGrid>
  <Card title="Локально по умолчанию" icon="laptop">
    Продолжайте работать без подключения к интернету. Документы хранятся на вашем устройстве, если вы не решите сохранить их в другом месте.
  </Card>
  <Card title="Используйте своё облако" icon="rocket">
    Подключите сервисы WebDAV, например Nextcloud, чтобы синхронизировать, резервировать и редактировать заметки откуда угодно.
  </Card>
  <Card title="Программное обеспечение с открытым кодом" icon="code-branch">

  </Card>
  <Card title="Творите вместе" icon="comment">
    Экспериментальная совместная работа поддерживает сквозное шифрование сеансов через Swamp или самостоятельно размещаемый сервер WebSocket.
  </Card>
</CardGrid>
