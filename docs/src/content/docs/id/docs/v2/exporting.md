---
title: Exporting
---

Use **Export** in the Butterfly menu while a document is open. Pick a Butterfly note format when you want to preserve the note for later editing, or choose an output format to share its appearance with another app.

| Format                                     | Use it for                                                                                   |
| ------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Packaged file (`.bfly`) | A compact, editable Butterfly note.                                          |
| Raw file (`.tbfly`)     | An editable, text based Butterfly note that works well with version control. |
| Gambar                                     | A raster picture of the selected view or page.                               |
| SVG                                        | A vector export of the selected view or page.                                |
| PDF                                        | One or more pages or areas for printing or sharing.                          |
| Xournal++                                  | Moving a copy of the note to Xournal++.                                      |

See [Storage](../storage/#supported-file-types) for more about Butterfly note files. Image, SVG, PDF, and Xournal++ exports should be treated as output copies rather than substitutes for your editable Butterfly note.

## Export an image or SVG {#export-an-image-or-svg}

1. Open the Butterfly menu and choose **Export → Image** or **Export → SVG**.
2. In the preview dialog, select **View** to use the current viewport or **Page** to fit the page content.
3. Adjust the position, size, scale, rotation, or padding if needed. Image exports also have image specific options.
4. Choose **Export** to save the file. **Share** is offered on supported platforms.

The pin button in this dialog adds an Export action to the document toolbar using the current settings. Selecting that action opens the export dialog again, so you can review it before saving.

You can also use an [area](../areas/) to define a particular region of the canvas for export.

## Export a PDF {#export-a-pdf}

Choose **Export → PDF**. The PDF dialog contains a list of areas to export. Add areas from the document, adjust their order and settings, and export the result. You can save the area list as a preset and reuse an existing preset later.

PDF export is useful when you need fixed pages from Butterfly's infinite canvas. Set up [areas](../areas/) around the content you want on each output page before exporting.
