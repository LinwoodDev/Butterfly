---
title: Spacer tool
---

With this tool you can add space between elements by dragging where you want to add space. Note that [Areas](../../areas) are not affected by this tool. Only their content is.

## Διαμόρφωση

| Ιδιότητα   | Προεπιλογή | Περιγραφή                                                                      |
| ---------- | ---------- | ------------------------------------------------------------------------------ |
| Κατεύθυνση | Οριζόντια  | Choose whether the tool adds space horizontally or vertically. |
