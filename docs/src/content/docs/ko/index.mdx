  ## Butterfly를 나만의 작업 흐름에 맞추세요

  좋아하는 배경, 도구, 레이어, 영역, 페이지를 모은 템플릿으로 시작하세요. 재사용할 콘텐츠는 팩으로 저장해 다음 프로젝트를 필요한 모든 것과 함께 시작할 수 있습니다.
</LandingFeature>

<LandingFeature image={crossplatform} darkImage={crossplatformDark} alt="휴대폰과 데스크톱의 손글씨 Butterfly 문서">





  ## 어디서나 작동합니다

  책상 위의 캔버스를 다음 수업이나 회의로 가져가세요. Butterfly는 Android, Windows, macOS, Linux, 브라우저에서 실행되며 iOS 미리 보기 버전도 있습니다.

</LandingFeature>
