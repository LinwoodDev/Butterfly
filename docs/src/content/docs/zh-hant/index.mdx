  ## 為視覺思考者而設的工作空間

  用觸控筆記錄課堂筆記、在 PDF 上標註、勾勒介面、建立圖表、規劃專案，或把它們全都放進同一份文件裡。

</LandingFeature>

<LandingFeature image={penLight} darkImage={penDark} alt="Butterfly 繪圖工具的筆設定" reverse>





  ## 微調每一筆

  使用觸控筆、觸控或滑鼠繪圖。調整筆畫粗細、色彩、平滑度與質感。若有筆畫不盡理想，直接編輯即可，不必從頭來過。
</LandingFeature>

## 專案成長，能力也隨之擴展

<CardGrid stagger>
  <Card title="每個元素都能持續編輯" icon="pencil">
    放置內容後，仍可移動、調整大小與顏色，或重新編排。第一次嘗試不必就是最終版本。
  </Card>
  <Card title="常見媒體，集中於一份文件" icon="document">
    匯入相機照片、圖庫圖片、PDF 與 SVG，和自己的筆記結合，再以常用格式匯出乾淨的成果。
  </Card>
  <Card title="可重複使用的素材" icon="puzzle">
    把喜愛的版面做成範本，常用內容變成套件、印章、色盤與樣式，供所有文件使用。
  </Card>
  <Card title="每個想法都有合適工具" icon="open-book">
    不只筆與橡皮擦，還有標籤、形狀、多邊形、尺規、格線、材質、印章、雷射筆、簡報工具等。
  </Card>
</CardGrid>

<LandingFeature image={collageLight} darkImage={collageDark} alt="具備可重複使用畫布樣式的 Butterfly 範本與套件">




  ## 讓 Butterfly 配合你的工作流程

  從集合你喜愛背景、工具、圖層、區域與頁面的範本開始。將可重複使用的內容存成套件，讓下一個專案一開始就具備所需的一切。
</LandingFeature>

<LandingFeature image={crossplatform} darkImage={crossplatformDark} alt="在手機與桌上型電腦上顯示的手寫 Butterfly 文件" reverse>





  ## 隨處都能使用

  把畫布從書桌帶到下一堂課或會議。Butterfly 可在 Android、Windows、macOS、Linux 和瀏覽器中執行，也提供 iOS 預覽版。

</LandingFeature>

## 你的作品屬於你

<CardGrid>
  <Card title="預設儲存在本機" icon="laptop">
    沒有網路連線也能繼續工作。除非你選擇儲存到其他地方，文件都會留在自己的裝置上。
  </Card>
  <Card title="使用自己的雲端" icon="rocket">
    連接 Nextcloud 等 WebDAV 服務，隨時隨地同步、備份與編輯筆記。
  </Card>
  <Card title="開放原始碼軟體" icon="code-branch">
    Butterfly 依 GNU AGPL-3.0 授權條款免費開放原始碼。文件可保存在有完整文件說明的 `.bfly` 與 `.tbfly` 格式中。
  </Card>
  <Card title="一起創作" icon="comment">
    實驗性的協作功能支援透過 Swamp 或自行架設的 WebSocket 伺服器進行端對端加密連線。
  </Card>
</CardGrid>
