---
title: Stamp tool
---

The stamp tool allows you to add components to your canvas.
Mevcut bir paketi kullanın, kendi paketinizi oluşturun veya kullanmak için bir paketi içe aktarın. Read more [here](../../pack).

## Yapılandırma

| Özellik   | Varsayılan | Tanım                                                                                                                                           |
| --------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Component | Yok        | The selected component from a pack to place on the canvas. You can clear the selection in the properties panel. |
