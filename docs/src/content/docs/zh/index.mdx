  ## 为视觉思考者打造的工作空间

  用触控笔记录课程笔记、批注 PDF、勾勒界面、创建图表、规划项目，或把它们全部放进同一份文档中。

</LandingFeature>

<LandingFeature image={penLight} darkImage={penDark} alt="Butterfly 绘图工具的画笔设置" reverse>





  ## 精调每一笔

  使用触控笔、触摸或鼠标绘图。调整笔画粗细、颜色、平滑度和纹理。如果有一笔不够理想，直接编辑即可，无需从头开始。
</LandingFeature>

## 项目成长，能力随之扩展

<CardGrid stagger>
  <Card title="每个元素始终可编辑" icon="pencil">
    内容放置后，仍可移动、调整大小与颜色，或重新编排。第一次尝试不必就是最终版本。
  </Card>
  <Card title="常见媒体汇集于一份文档" icon="document">
    导入相机照片、图库图片、PDF 和 SVG，与自己的笔记结合，并以常用格式导出整洁的成果。
  </Card>
  <Card title="可复用的构建模块" icon="puzzle">
    将喜爱的布局制成模板，将常用内容变成资源包、印章、调色板和样式，供所有文档使用。
  </Card>
  <Card title="适合每个想法的工具" icon="open-book">
    不只有画笔和橡皮擦，还可使用标签、形状、多边形、尺子、网格、纹理、印章、激光笔、演示工具等。
  </Card>
</CardGrid>

<LandingFeature image={collageLight} darkImage={collageDark} alt="带有可复用画布样式的 Butterfly 模板和资源包">




  ## 让 Butterfly 适应你的工作流程

  从汇集你喜爱的背景、工具、图层、区域和页面的模板开始。把可复用内容保存为资源包，让下一个项目从一开始就具备所需的一切。
</LandingFeature>

<LandingFeature image={crossplatform} darkImage={crossplatformDark} alt="在手机和台式电脑上显示的手写 Butterfly 文档" reverse>





  ## 随处可用

  将画布从桌面带到下一节课或下一场会议。Butterfly 可在 Android、Windows、macOS、Linux 和浏览器中运行，也提供 iOS 预览版。

</LandingFeature>

## 你的作品属于你

<CardGrid>
  <Card title="默认保存到本地" icon="laptop">
    即使没有网络连接也能继续工作。除非你选择保存到其他位置，文档都会留在自己的设备上。
  </Card>
  <Card title="使用自己的云端" icon="rocket">
    连接 Nextcloud 等 WebDAV 服务，随时随地同步、备份和编辑笔记。
  </Card>
  <Card title="开源软件" icon="code-branch">
    Butterfly 在 GNU AGPL-3.0 许可下免费开源。可将文档保存在有完整文档说明的 `.bfly` 和 `.tbfly` 格式中。
  </Card>
  <Card title="一起创作" icon="comment">
    实验性的协作功能支持通过 Swamp 或自行托管的 WebSocket 服务器进行端到端加密会话。
  </Card>
</CardGrid>
