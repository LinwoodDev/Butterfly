## Windows SmartScreen

Windows ostrzega użytkowników przy instalacji oprogramowania bez certyfikatu.

![Smart screen](@assets/img/smart-screen.png)

Aby zainstalować aplikację, musisz kliknąć w "Więcej informacji".

![Smart screen więcej informacji](@assets/img/smart-screen-more-info.png)

Następnie kliknij "Uruchom mimo to".
