import { CardGrid } from '@astrojs/starlight/components';
import DownloadButton from '/src/components/DownloadButton.astro';

:::note

Jest to postępowa aplikacja internetowa. Możesz go zainstalować w przeglądarce i używać w trybie offline.
Wszystkie dane są przechowywane w przeglądarce.

Wersja internetowa działa we wszystkich nowoczesnych przeglądarkach, ale jest bardziej wydajna w przeglądarkach opartych na Chromium ze względu na ich wsparcie dla WebAssembly (Wasm). Firefox i Safari nie obsługują obecnie wymaganych funkcji Wasm. Zobacz [dokumentację zgodności przeglądarki Flutter's browser](https://docs.flutter.dev/platform-integration/web/wasm#learn-more-about-browser-compatibility), po więcej informacji.

:::

## Wersje

Główne i podgląd (rozwijają) Motylki nie są takie same jak wersje stabilne i nocne.
Nie są one bezpośrednio związane z wydaniem. Są one aktualizowane natychmiast po wypychaniu nowego zobowiązania do repozytorium.
