  ## התאימו את Butterfly לדרך העבודה שלכם

  התחילו עם תבנית שמאגדת את הרקעים, הכלים, השכבות, האזורים והדפים המועדפים עליכם. שמרו תוכן לשימוש חוזר בחבילות, כדי שהפרויקט הבא יתחיל עם כל מה שצריך.
</LandingFeature>

<LandingFeature image={crossplatform} darkImage={crossplatformDark} alt="מסמך Butterfly בכתב יד בטלפון ובמחשב שולחני" reverse>





  ## עובד בכל מקום

  קחו את הבד משולחן העבודה לשיעור או לפגישה הבאה. Butterfly פועל ב-Android, Windows, macOS, Linux ובדפדפן; זמינה גם תצוגה מקדימה ל-iOS.

</LandingFeature>
