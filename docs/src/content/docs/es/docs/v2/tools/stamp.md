---
title: Stamp tool
---

The stamp tool allows you to add components to your canvas.
Use an existing [pack](../../pack/) or create one with a reusable [component](../../pack/#components).

## Configuración

| Propiedad  | Por defecto | Descripción                                                                                                                                     |
| ---------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Componente | Ninguna     | The selected component from a pack to place on the canvas. You can clear the selection in the properties panel. |
