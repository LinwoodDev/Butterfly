---
title: Stamp tool
---

The stamp tool allows you to add components to your canvas.
Використовуйте наявний пакунок, створіть свій власний або імпортуйте пакет. Read more [here](../../pack).

## Конфігурація

| Властивість | Типово     | Опис                                                                                                                                            |
| ----------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Компонент   | Без ефекту | The selected component from a pack to place on the canvas. You can clear the selection in the properties panel. |
