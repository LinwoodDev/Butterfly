  ## 視覚的に考える人のためのワークスペース

  スタイラスで講義ノートを取り、PDFに注釈を付け、インターフェースをスケッチし、図を作り、プロジェクトを計画する。すべてを1つの文書にまとめることもできます。

</LandingFeature>

<LandingFeature image={penLight} darkImage={penDark} alt="Butterflyの描画ツールのペン設定" reverse>





  ## 一筆ごとにこだわる

  スタイラス、タッチ、マウスで描けます。線の太さ、色、滑らかさ、質感を調整できます。思いどおりでない線は、最初からやり直さずに編集できます。
</LandingFeature>

## プロジェクトが大きくなってもパワフル

<CardGrid stagger>
  <Card title="すべての要素を編集可能" icon="pencil">
    配置した後でも、コンテンツの移動、サイズ変更、色変更、並べ替えができます。最初の試みを完成形にする必要はありません。
  </Card>
  <Card title="さまざまなメディアを1つの文書に" icon="document">
    カメラ写真、ギャラリー画像、PDF、SVGを読み込み、自分のメモと組み合わせられます。一般的な形式で整った結果を書き出せます。
  </Card>
  <Card title="再利用できる素材" icon="puzzle">
    お気に入りのレイアウトはテンプレートに、よく使う内容はパック、スタンプ、パレット、スタイルにして、すべての文書で使えます。
  </Card>
  <Card title="あらゆるアイデアのためのツール" icon="open-book">
    ペンや消しゴムだけでなく、ラベル、図形、多角形、定規、グリッド、テクスチャ、スタンプ、レーザーポインター、プレゼンテーションツールなどを使えます。
  </Card>
</CardGrid>

<LandingFeature image={collageLight} darkImage={collageDark} alt="再利用可能なキャンバススタイルを備えたButterflyのテンプレートとパック">




  ## Butterflyを自分のワークフローに合わせる

  お気に入りの背景、ツール、レイヤー、エリア、ページをまとめたテンプレートから始めましょう。再利用する内容をパックに保存すれば、次のプロジェクトを必要なものがそろった状態で始められます。
</LandingFeature>

<LandingFeature image={crossplatform} darkImage={crossplatformDark} alt="スマートフォンとデスクトップで表示した手書きのButterfly文書" reverse>





  ## どこでも使える

  デスクのキャンバスを次の授業や会議にも持ち出せます。ButterflyはAndroid、Windows、macOS、Linux、ブラウザで動作し、iOSのプレビューも利用できます。

</LandingFeature>

## あなたの作品はあなたのもの

<CardGrid>
  <Card title="標準でローカル保存" icon="laptop">
    インターネットに接続していなくても作業を続けられます。別の場所への保存を選ばない限り、文書はあなたのデバイスに保存されます。
  </Card>
  <Card title="自分のクラウドを使う" icon="rocket">
    NextcloudなどのWebDAVサービスに接続すれば、どこからでもメモの同期、バックアップ、編集ができます。
  </Card>
  <Card title="オープンソースソフトウェア" icon="code-branch">
    ButterflyはGNU AGPL-3.0ライセンスの無料オープンソースソフトウェアです。文書は文書化された`.bfly`と`.tbfly`形式で保管できます。
  </Card>
  <Card title="一緒に作る" icon="comment">
    実験的な共同作業機能は、Swampまたは自分でホストするWebSocketサーバーを通じたエンドツーエンド暗号化セッションに対応しています。
  </Card>
</CardGrid>
