title: Vorlagen
---

In Butterfly sind Vorlagen eine hilfreiche Möglichkeit, ein Dokument als Ausgangspunkt für die schnelle Nutzung zu verwenden.

For example, if you like having a [highlighter](../tools/pen/) and a dotted [background](../background/) when taking notes, you can use templates to quickly apply the tools you need and the specific background you like.

## Was speichern Vorlagen?

Vorlagen sind im Grunde Dokumente, die Sie als Ausgangspunkt verwenden.

They store everything a normal Dokument does, including:

- [Tools](../tools/)
- Dokumentinhalt wie Bilder, Zeichnungen, Striche usw.
- Die Einstellungen für jedes Werkzeug
- [Layers](../layers/)
- [Areas](../areas/)
- [Pages](../pages/)

## Wie erstellt man eine Vorlage?

Make a note with the content, tools, pages, and background you want to reuse. Open the Butterfly menu, choose **Templates**, then select **Create** in the template dialog. Enter a name. The file name and directory fields are optional; use them if you want to control how the template is stored.

When creating another note, select a template from the Home view's Quickstart section or choose **Templates** from the Butterfly menu in an open document. Creating a note from a template makes a separate document, so later edits to that note do not change the template.

The template dialog can switch storage connections and export templates as packaged or raw Butterfly files. You can also select multiple user templates to export or delete them.

## Wo finde ich weitere Vorlagen?

Export a template from the template dialog to share it as a Butterfly file. You can also share templates with the community through [Matrix or Discord](/community/).
