---
title: Wiederholen-Werkzeug
---

:::note[⚡ Aktionswerkzeug]

This is a special action tool.
It can't be selected and will run the action immediately when you click on it.

:::

Wenn Sie dieses Werkzeug anklicken, wird Ihre letzte Aktion wiederholt.
Siehe [Undo-Tool](../undo) um die letzte Aktion rückgängig zu machen.
