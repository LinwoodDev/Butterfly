---
title: Rückgängig-Werkzeug
---

:::note[⚡ Aktionswerkzeug]

This is a special action tool.
It can't be selected and will run the action immediately when you click on it.

:::

Wenn Sie dieses Werkzeug anklicken, machen Sie Ihre letzte Aktion rückgängig.
Siehe [Wiederholen](../redo), um die letzte Aktion zu wiederholen.
