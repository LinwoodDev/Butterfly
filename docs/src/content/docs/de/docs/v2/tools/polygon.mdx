import {Check, Trash, Polygon} from "@phosphor-icons/react";

Mit diesem Werkzeug können Sie eigene Formen erstellen.

## Verwendung

1. Klicken Sie auf die Leinwand, um den ersten Punkt des Polygons hinzuzufügen.
2. Klicken Sie erneut, um weitere Punkte hinzuzufügen.
3. Nun haben Sie drei Möglichkeiten, das Polygon abzuschließen:
   1. Click in the toolbar on the <Check className="inline-icon" /> `Finish` button. This will connect the last point to the first
      point.
   2. Click in the toolbar on the <Polygon className="inline-icon" /> `Submit` button. This will create the polygon without connecting
      the last point to the first.
   3. Wechsle das Werkzeug. This will also create the polygon without connecting the last point to the
      first.
4. If you want to remove the selected point, click on the <Trash className="inline-icon" /> `Delete` button in the toolbar.
5. To edit a point, click on it and drag it to round it off. To return to edit mode, open its [Context menu](../../context_menu) and click <Polygon className="inline-icon" /> `Edit`.

## Bézier Curves

You can use this tool to create Bézier Curves which gives your shape a smooth curvature.
To adjust the curvature around a selected point, drag on the paper until a tangent line appears.

## Symbolleiste

While in Polygon edit mode the toolbar contains the following buttons:

* <Trash className="inline-icon" /> `Delete` - Allows you to delete the selected point of the polygon.
* <Check className="inline-icon" /> `Finish` - Connects the last point to the first point, completing the polygon.
* <Polygon className="inline-icon" /> `Submit` - Completes the polygon without connecting the last point to the first.
